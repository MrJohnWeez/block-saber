# Test fixtures

Maps the converter pipeline is tested against. Committed zips are read-only test data; regenerate the synthetic ones with `node dev/make-fixtures.mjs` (outputs git-ignored zips here in `synthetic/`).

## `maps/` — committed real maps

| File                                                                            | Format                 | Origin                                                                                                                                                                          |
| ------------------------------------------------------------------------------- | ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `DifficultyTestSong.zip`, `EndShort.zip`, `HotBeat2.zip`, `RedWallTest.zip`     | v2                     | Own fixtures from the Unity repo (`UnitTestFiles/`), used for output regression                                                                                                 |
| `InvalidData.zip`, `MissingCover.zip`, `MissingSong.zip`, `MissingSongData.zip` | v2 (broken on purpose) | Error-path fixtures from the Unity repo                                                                                                                                         |
| `beatsaver-v4-443f3.zip`                                                        | v4.0.1 ("15 Minutes")  | [BeatSaver key 443f3](https://beatsaver.com/maps/443f3), uploader Lekrkoekj, fetched 2026-11-25 from `https://r2cdn.beatsaver.com/db330ce9bd44693d185d68713428f72744c252bc.zip` |
| `bsmg-v3-official-sample.zip`                                                   | v3.3.0                 | Beatmap file is the official schema sample `beatmap/3.3.0.dat` from [bsmg/wiki](https://github.com/bsmg/wiki), wrapped with a minimal v3 `Info.dat`, placeholder audio/cover    |

Fetched-map provenance is recorded in `maps/fetched.jsonl`.

**BeatSaver caveat discovered while assembling this folder:** BeatSaver's CDN only ever serves v2-shaped zips for maps uploaded before the v4 era (older uploads were re-hosted normalized to v2), so a true community-v3 zip could not be sourced there — hundreds of 2021–2023 ranked maps all parse as `_version: 2.x`. The official BSMG schema sample stands in for v3; see `docs/migration/` and the plan file.

## `synthetic/` — generated by `dev/make-fixtures.mjs`

Tiny deterministic maps (120 BPM) for parser and emitter unit tests. Audio is a copied game sound, covers are the site logo.

| File                             | Exercises                                                                                                                                    |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `syn-v2-basic.zip`               | v2 full cut-direction spread, bombs as `_type: 3`, all 4 wall shapes, light events, `_timeOffset`                                            |
| `syn-v3-basic.zip`               | v3 short-key schema, `customData.offset`, fractional-duration walls (B5), sliders/burst-sliders (must be skipped or dotted per contract doc) |
| `syn-v3-bpm.zip`                 | v3 `bpmEvents` 120 → 180 at beat 8 — the BPM-change timing math (B4)                                                                         |
| `syn-v3-walls.zip`               | v3 wall-shape matrix (contract §3.4): tall vs floating-crouch bands, `y ≤ 1 && h ≥ 3` boundary, low walls collapsing to short, widths 1–5 (≥5 clamp), fractional durations (B5) |
| `syn-v3-two-characteristics.zip` | Standard Expert + Lawless Expert (B3 characteristic collision)                                                                               |
| `syn-v4-basic.zip`               | v4 flat `difficultyBeatmaps`, `colorNotesData` index indirection, separate lightshow file                                                    |
| `syn-info-lowercase.zip`         | lowercase `info.dat` entry name (B6 case-insensitive lookup)                                                                                 |

Bug IDs (B1–B6) refer to the bug table in the master plan (`~/.opencode/plan/block-saber-web-migration.md`, mirrored in `docs/migration/`).
