    Installing your converted packs

    1. If you don't have the base game yet, install it first using the downloads above: the game world, or the base datapack plus base resource pack for a world of your own.
    2. Download each song's datapack with the button on its row above, and drop the zips (unzipped) into your Block Saber world's datapacks folder: .minecraft/saves/<world>/datapacks/.
    3. Download the songs pack ("Block Saber Songs") and put that single zip into .minecraft/resourcepacks/ — do not unzip it.
    4. In Minecraft, open Options → Video Settings → Resource Packs, move "Block Saber base assets and sounds" and "Block Saber Songs" to the selected list, and apply. Re-download and replace the songs pack whenever you convert new songs.
    5. Open your Block Saber world and run /reload (or re-enter the world) to load the new songs — each song registers itself automatically, no command needed. A working install says BlockSaber Re-Loaded! in chat and shows three enabled packs to /datapack list.
    6. Play: the menu lives in your inventory as items — drop the item you want with Q (Game Selection → a song → a difficulty starts the run). If your inventory is ever empty, the game hands the menu back on the next tick.
    Minecraft 26.3 or newer is required. Packs made by this site use the new song contract and are not compatible with packs from the old 1.18.2-era generator — delete any old Block Saber base and song datapacks and resource packs before installing. The base game will refuse mismatched packs in chat.
